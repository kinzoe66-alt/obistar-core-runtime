# System Foundation

## Core Architecture

The system is a:

- continuity-governed operational substrate
- intent-governed application environment
- declarative operational topology system

Applications are NOT modeled as:
- pages
- forms
- screens
- isolated workflows

Applications ARE modeled as:
- constrained operational tunnels
- continuity environments
- operational intent topologies

---

## Core Insight

Operational workflows already exist before software.

Software should:
- stabilize continuity
- reduce cognition fragmentation
- preserve replay trust
- compress operational uncertainty

NOT:
invent arbitrary workflows.

---

## Constraint Tunnel Model

Environment constraints define:
- authority boundaries
- operational legality
- transition legality
- continuity requirements
- risk topology
- workflow expectations

Everything else becomes:
adaptive conductors routed through the tunnel.

Examples:
- UI
- APIs
- onboarding
- replay
- batching
- notifications
- workflows
